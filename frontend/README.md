# Frontend Service

The Frontend Service provides the graphical user interface for the Log Management System. It is developed using React, Vite, and Tailwind CSS.

## Core Features
1. **Interactive Dashboard:** Displays critical metrics including Total Events, Top Source IPs, Top Users, and Top Event Types.
2. **Timeline Visualization:** Provides a chronological histogram of log events, enabling administrators to identify traffic spikes.
3. **Alert Management:** Displays a historical record of security alerts generated by the backend threshold monitoring.
4. **Data Filtering:** Allows administrators to filter data streams by Tenant and Time Range.
5. **Secure Routing:** Implements Nginx as a reverse proxy in production to securely route API requests and serve static assets over HTTPS (TLS).

## Development Setup

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
